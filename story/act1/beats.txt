# Act 1: The Previous Tenant. SPOILERS.
#
# Format (internal/script):
#   beat      id
#   chapter   1-5
#   required  yes          required beats fire in file order within a chapter
#   invite    yes          firing this lets `tenant` open the finale
#   after     other-id     an optional beat that waits for another beat
#   mech      mechanic     see docs/EVENTS.md
#   text      ...          alternatives, tried in order until one renders
#   fallback  mechanic     used if the mechanic can't work in this shell,
#   ftext     ...          or if the chapter stalls
#
# Variables: {{user}} {{host}} {{cwd}} {{cwd.off}} {{names.here}}
# {{names.elsewhere}} {{last_night.dir}} {{last_night.time}}
# {{first_seen.dir}} {{cmd.top}} {{cmd.rare}} {{days}} {{typo}}
# {{typo.meant}} {{cmds.total}} {{dirs.count}}
#
# Rules: lowercase, short, specific, never a threat, never a power it
# doesn't have. Ghost commands must be harmless if someone presses Enter.


# ── chapter 1: off ─────────────────────────────────────────────────────
# Deniable. Every one of these has a boring explanation available.

beat      off-glyph
chapter   1
